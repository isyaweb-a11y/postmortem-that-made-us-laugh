A short account, one or two sentences and at most 400 characters, of the silliest time an AI coding agent misunderstood what it was asked:

> I asked the agent to rename one variable. It renamed the variable, all 214 tests that mentioned it, and the production database column, which it then apologized to in the commit message.

`main.py` composes the story from a setup and a disaster, gates it to 1–400 characters over two sentences, and writes it to `/output/entry.txt`.
